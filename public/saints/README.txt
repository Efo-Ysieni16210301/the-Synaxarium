Put one image per saint here, named to match that saint's `imageId`
in the JSON data - e.g. if a saint's entry has "imageId": "bartholomew.jpg",
put the file at /public/saints/bartholomew.jpg.

Recommended format: .jpg or .webp, roughly 800x800px (square), kept
under ~200KB each so the offline install stays small - hundreds of
saints x multi-MB images adds up fast on a phone.

LICENSING: traditional icon paintings, Telegram-post photos, and
images copied from church websites are usually still someone's
copyrighted work, even when shared freely online. Before shipping,
make sure you either:
  - drew/photographed/generated the images yourself,
  - have images explicitly marked public-domain or openly licensed
    (e.g. certain very old icon reproductions), or
  - got permission from whoever holds the rights.
